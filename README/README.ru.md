Универсальный инструмент создания событий для VRChat, который избавляет от повторяющейся настройки.
Создавайте и сохраняйте шаблоны событий для каждой группы, генерируйте ближайшие даты из простых повторяющихся паттернов и мгновенно заполняйте детали. Идеально подходит для быстрого планирования еженедельных встреч, просмотровых вечеров и событий сообщества.

## Шаблоны и нативные серии бок о бок

В VRChat появилась собственная функция повторяющихся событий. Она хорошо подходит для стабильных, регулярно повторяющихся встреч: после создания серия поддерживается самим VRChat, приложение можно даже не открывать, а вся серия анонсируется один раз в момент создания. Редактирование запущенной серии в VRChat обычно означает её удаление и повторное создание; это приложение делает этот шаг за вас, когда вы меняете расписание, поэтому процесс ощущается как обычное редактирование. Минус в том, что отдельных уведомлений по каждому случаю нет: правки, внесённые в отдельные события позже, могут пройти мимо внимания вашего сообщества.

С шаблонами всё иначе. Основной поток ручной: вы создаёте по одному событию, а шаблон заполняет за вас форму, чтобы не приходилось каждый раз вводить детали заново. Поверх этого можно включить опциональную автоматизацию, которая будет публиковать следующие события по расписанию, и каждая публикация выходит со своим собственным анонсом, чтобы сообщество знало, когда планируется новое мероприятие. Если в ожидающее событие внести изменения, они будут озвучены вместе с публикацией, так что правки в последний момент никем не пропускаются. Минус: для автоматической публикации приложение должно быть запущено.

Оба варианта живут в одной и той же вкладке **Управление расписаниями**. В одной группе можно использовать что-то одно или сразу оба, в зависимости от того, что лучше подходит к событию.

## Возможности
- Шаблоны, которые автоматически заполняют детали события для каждой группы (с опциональной автоматизацией для публикации по расписанию).
- Генератор повторяющихся шаблонов со списком ближайших дат и ручным вводом даты/времени.
- Поддержка нативных серий VRChat: параллельно с шаблонами.
- Автоматизация событий: публикует события по шаблонам, пока приложение запущено.
- Раздел «Редактировать события» для будущих событий (сетка + модальное окно редактирования, с фильтрами и регулируемым диапазоном времени).
- Мастер создания событий для групповых календарей.
- Theme Studio с пресетами и полным управлением цветами интерфейса (поддержка #RRGGBBAA).
- Локализация с выбором языка при первом запуске (en, fr, es, de, ja, zh, pt, ko, ru, nl).
- Выбор и загрузка изображений из галереи по ID.
- Запуск при старте системы + сворачивание в системный трей.
- Защита от запуска нескольких экземпляров приложения одновременно.

### Опциональные интеграции (Расширенные настройки)

По умолчанию выключены, для каждой требуется отдельная настройка. После настройки каждая интеграция включается и выключается отдельно для каждого шаблона и каждого события:

- **Discord:** автоматически создаёт запланированные события Discord одновременно с событиями VRChat. Требуется создать Discord-бота и пригласить его на ваш сервер. ([Руководство по настройке](Discord%20Setup/DISCORD_SETUP.ru.md))
- **Календарь:** генерирует файлы `.ics` с напоминаниями, доставляемые через Discord-вебхук или сохраняемые локально. ([Руководство по настройке](Calendar%20Setup/CALENDAR_SETUP.ru.md))
- **EC Kit** (платная лицензия): настройка идентичности вебхука для каждой группы (отображаемое имя, аватар, цвет embed-а), а также пользовательские сообщения и вложения с изображениями для каждого события. ([Ko-fi](https://ko-fi.com/s/0735ce5375) · [Лицензия](https://eckit.cynacedia.dev/license/v1.0))

## Конфиденциальность и хранение данных
Ваш пароль не сохраняется. Кэшируются только сессионные токены.
Приложение хранит свои файлы в каталоге пользовательских данных Electron (показывается в Настройки > Информация о приложении):

- `profiles.json` (шаблоны событий и настройки интеграций для каждой группы)
- `series.json` (нативные серии VRChat, отслеживаемые локально)
- `cache.json` (сессионные токены)
- `settings.json` (настройки приложения)
- `themes.json` (пресеты тем и пользовательские цвета)
- `pending-events.json` (очередь автоматизации)
- `automation-state.json` (отслеживание автоматизации)
- `pending-rasterize.json` (создания серий в очереди после ограничения частоты запросов)

Вы можете переопределить каталог данных с помощью переменной окружения `VRC_EVENT_DATA_DIR`.
При первом запуске приложение попытается импортировать существующий `profiles.json` из папки проекта.

Токены бота (для интеграции с Discord) и URL-адреса вебхуков шифруются при хранении с использованием безопасного хранилища вашей операционной системы. Они не отправляются никуда, кроме напрямую в API Discord или на ваш URL вебхука.

__**Не делитесь файлами кэша и папками данных приложения.**__

## Заметки по использованию
- Шаблоны требуют название расписания, название события и описание перед сохранением.
- Приватные группы могут использовать только тип доступа = Группа.
- Длительность использует формат DD:HH:MM и ограничена 31 днём.
- Теги ограничены 5, языки 3.
- Загрузки в галерею ограничены PNG/JPG, 64-2048 px, до 10 МБ и 64 изображениями на аккаунт.
- VRChat ограничивает создание событий: не более 10 событий в час на человека на группу.
- Для автоматической публикации шаблонов приложение должно быть запущено. Серии после создания работают сами.
- Featured Event и другие специальные переключатели требуют определённых прав в группе; они появляются только при наличии разрешения.

## Устранение неполадок
- **Проблемы со входом:** удалите `cache.json` и войдите снова (используйте папку данных, показанную в Настройки > Информация о приложении).
- **Группы не отображаются в списке:** ваша учётная запись должна иметь доступ к календарю в целевой группе. Если вы только что обновили права на стороне VRChat, нажмите **Resync**, чтобы обновить список.
- **Ограничение частоты запросов:** VRChat может ограничивать создание событий. Подождите и попробуйте снова; остановитесь, если несколько попыток подряд провалились. Не нажимайте кнопки обновления и создания подряд.
- **Создание серии приостановлено:** если VRChat ограничил создание серии по частоте запросов, попытка повторится автоматически. На вкладке расписаний показывается время следующей попытки и есть кнопка «Повторить сейчас», если ждать не хочется.
- **Обновления:** некоторые функции блокируются, когда есть отложенное обновление. Скачайте и запустите последнюю версию.
