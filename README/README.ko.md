반복적인 설정을 줄여주는 VRChat용 올인원 이벤트 생성 도구입니다.
그룹별 이벤트 템플릿을 만들고 저장하며, 반복적인 일정의 세부 사항을 간단하게 즉시 설정할 수 있습니다. 주간 모임, 시청 파티, 커뮤니티 이벤트의 일정 설정에 적합합니다.

## 템플릿과 네이티브 시리즈, 어떻게 사용하나요

VRChat에는 자체적인 반복 이벤트 기능(시리즈)이 있으며, 안정적으로 반복되는 이벤트에 적합합니다. 시리즈를 한번 만들면 이후에는 VRChat이 알아서 운영하기 때문에 앱을 켜둘 필요가 없으며, 시리즈 전체에 대한 알림은 생성 시점에 한 번만 발생합니다. VRChat에서 진행 중인 시리즈를 직접 수정하려면 보통 시리즈를 삭제하고 다시 만들어야 하지만, 이 앱에서는 일정 변경 시 이러한 처리를 자동으로 수행하므로 일반적인 편집과 동일하게 사용할 수 있습니다. 다만 시리즈에는 개별 회차별 알림이 없기 때문에, 이후에 특정 회차를 수정해도 커뮤니티에 인지되지 않을 수 있습니다.

템플릿은 이와 다른 방식으로 동작합니다. 기본 흐름은 수동으로, 이벤트를 하나씩 만들 때 템플릿이 입력 양식을 자동으로 채워 매번 동일한 내용을 다시 입력할 필요가 없도록 합니다. 여기에 자동화 기능을 활성화하면 일정에 따라 다음 이벤트를 자동으로 게시할 수 있으며, 각 게시물은 개별 알림과 함께 발송되어 새 이벤트 일정을 커뮤니티에 미리 알릴 수 있습니다. 보류 중인 이벤트를 미리 수정해 두면 그 변경 내용도 게시 시점의 알림에 포함되므로, 막판 변경 사항이 누락될 일이 없습니다. 단, 자동 게시를 사용하려면 앱이 실행 중이어야 합니다.

두 방식 모두 동일한 **‘일정 관리’** 탭에서 사용할 수 있습니다. 같은 그룹에서 한 가지만 사용하거나 두 가지를 함께 사용할 수도 있으며, 이벤트 성격에 맞게 선택하시면 됩니다.

## 기능
- 그룹별 이벤트 세부 사항을 자동으로 채우는 템플릿 (선택적으로 일정에 따른 자동 게시 지원)
- 반복 패턴 생성기 (탬플릿의 날짜 목록 + 수동 날짜/시간 입력)
- VRChat 네이티브 시리즈 지원 (템플릿과 함께 사용 가능)
- 이벤트 자동화: 앱 실행 중에 템플릿 패턴에 따라 이벤트를 자동 게시
- 예정된 이벤트들의 보기 및 수정 (그리드 + 편집 모달, 필터 및 표시 기간 조정 지원)
- 그룹 캘린더 이벤트 생성을 위한 간단한 사용자 UI
- 프리셋이 포함된 테마 스튜디오와 전체 UI 색상 제어(#RRGGBBAA 지원)
- 첫 실행 시 다양한 언어 선택 가능 (en, fr, es, de, ja, zh, pt, ko, ru, nl)
- VRChat 갤러리 시스템의 이미지 ID를 통한 사진 선택 및 업로드
- 시스템 시작 시 실행 + 시스템 트레이로 최소화
- 단일 인스턴스 보호로 중복 실행 방지

### 선택적 연동 기능 (고급 옵션)

기본적으로 비활성화되어 있으며, 각각 별도의 설정이 필요합니다. 설정 후에는 템플릿과 이벤트별로 개별적으로 켜고 끌 수 있습니다:

- **Discord:** VRChat 이벤트와 함께 Discord 예정된 이벤트를 자동으로 생성합니다. Discord 봇을 만들어 서버에 초대해야 합니다. ([설정 가이드](Discord%20Setup/DISCORD_SETUP.ko.md))
- **캘린더:** 알림이 포함된 `.ics` 파일을 생성하여 Discord 웹훅으로 전송하거나 로컬에 자동 저장할 수 있습니다. ([설정 가이드](Calendar%20Setup/CALENDAR_SETUP.ko.md))
- **EC Kit** (유료 라이선스): 그룹별로 웹훅의 표시 이름, 아바타, 임베드 색상을 사용자 지정할 수 있으며, 이벤트별 사용자 지정 메시지와 이미지 첨부도 가능합니다. ([Ko-fi](https://ko-fi.com/s/0735ce5375) · [라이선스](https://eckit.cynacedia.dev/license/v1.0))

## 개인정보 및 데이터 저장
비밀번호는 저장되지 않습니다. 세션 토큰만 캐시됩니다.
앱 파일은 Electron 사용자 데이터 디렉터리에 저장됩니다(설정 > 애플리케이션 정보에서 확인):

- `profiles.json` (이벤트 템플릿 및 그룹별 연동 설정)
- `series.json` (로컬에서 관리하는 네이티브 VRChat 시리즈)
- `cache.json` (세션 토큰)
- `settings.json` (앱 설정)
- `themes.json` (테마 프리셋 및 사용자 색상)
- `pending-events.json` (자동화 대기열)
- `automation-state.json` (자동화 추적)
- `pending-rasterize.json` (호출 제한으로 인해 재시도를 기다리는 시리즈 생성 대기열)

시스템 환경 변수 `VRC_EVENT_DATA_DIR`로 데이터 디렉터리 경로를 변경할 수 있습니다.
첫 실행 시 앱은 프로젝트 폴더의 기존 `profiles.json`을 가져오려고 시도합니다.

봇 토큰(Discord 연동용)과 웹훅 URL은 OS의 보안 저장소를 사용하여 암호화됩니다. Discord API 또는 지정한 웹훅 URL 외에는 어디로도 전송되지 않습니다.

__**캐시 파일이나 앱 데이터 폴더를 공유하지 마세요.**__

## 사용 참고사항
- 템플릿에는 일정 이름, 이벤트 이름, 설명이 필요합니다.
- 비공개 그룹은 접근 유형을 그룹만 사용할 수 있습니다.
- 기간은 DD:HH:MM 형식이며 최대 31일입니다.
- 태그는 최대 5개, 언어는 최대 3개입니다.
- 갤러리 업로드 제한: PNG/JPG, 64-2048 px, 10MB 미만, 계정당 64장
- VRChat의 이벤트 생성은 시간, 사람, 그룹당 10개로 제한됩니다.
- 템플릿으로 이벤트를 자동 게시하려면 앱이 실행 중이어야 합니다. 시리즈는 한번 만들고 나면 VRChat 측에서 자동으로 운영합니다.
- Featured Event 등 특수 토글은 특정 그룹 권한이 필요하며, 허용된 경우에만 표시됩니다.

## 문제 해결
- **로그인 문제:** `cache.json`을 삭제하고 다시 로그인하세요. (설정 > 앱 정보에 표시된 데이터 폴더 사용)
- **그룹이 보이지 않음:** 대상 그룹에 대한 캘린더 접근 권한이 필요합니다. VRChat 측에서 권한을 방금 변경했다면 상태 표시줄의 **‘재동기화’** 버튼을 눌러 그룹 목록을 새로 고침할 수 있습니다.
- **호출 제한:** VRChat에서 이벤트 생성에 제한을 둘 수 있습니다. 잠시 기다렸다가 재시도하고, 여러 번 실패하면 중지하세요. 새로고침/이벤트 생성 버튼을 반복 클릭하지 마세요.
- **시리즈 생성이 일시 중지됨:** VRChat의 호출 제한으로 시리즈 생성이 중단되면 자동으로 재시도됩니다. 일정 관리 탭에 다음 재시도 시각이 표시되며, ‘지금 재시도’ 버튼으로 즉시 재시도할 수도 있습니다.
- **업데이트:** 업데이트가 대기 중일 때 일부 기능이 차단됩니다. 최신 릴리스가 다운로드 완료된 뒤에 다시 실행하세요.
